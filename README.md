# Pipeline de proyectos (boceto)

Boceto del tablero de proyectos de Riokrisol: un tablero **comercial** (de prospecto a ganado) y uno de **operación** (de diagnóstico a graduado), con una franja por título minero y sus subcontratos adentro. Las fichas se arrastran entre etapas; al ganar un negocio, los subcontratos pasan a operación.

Todos los datos son de ejemplo e inventados. No corresponde a ningún proyecto real. No guarda nada: al recargar la página vuelve al estado inicial.

Es un único archivo, `index.html`, sin dependencias salvo las tipografías de Google Fonts.
